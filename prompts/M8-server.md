# Prompt M8 — Server

> Depends on: M7. Owner: Server. Estimate: ~24 h.
> Owns the latency metric (15%). **Ship the stub on day 4 so the client team is never blocked.**

---

Read `CLAUDE.md`. You are implementing M8: a FastAPI service in front of vLLM, one endpoint,
session state in memory, and a structured trace the eval harness reads directly. Nothing
more — the server is not where the marks are.

## Model choice

An open-weights, Apache-2.0, self-hostable VLM of the Qwen-VL class, served with vLLM.
ISRO's brief requires offline deployability; a hosted API undoes the entire privacy argument
the client just spent twenty minutes making, and a judge will ask.

**Verify the current Qwen-VL release before writing the prompt** — the line moves fast. Take
the smallest size that clears your accuracy bar; on GUI tasks with a good element list,
small models do far better than expected because the DOM has already done the hard
perception. Keep Qwen2.5-VL-7B-Instruct as the boring, heavily-documented fallback.

## Build order

**1. `server/app.py` with a stub planner — do this first.** Returns canned actions matching
the contract. It unblocks the client on day 4 and costs an hour. Everything else can wait
for a GPU.

**2. vLLM up with a health check.** A raw completion returns within the latency budget.

**3. Guided decoding** against `server/schema.json` (generated by M7). One config flag, and
it removes an entire class of demo failure. Verify: 100 consecutive generations parse
without a retry.

**4. `server/planner.py`** — prompt construction and response handling.

## System prompt skeleton

```
You operate a web page through a privacy-preserving browser agent.

You never receive raw user data. Sensitive values are replaced by placeholders of
the form «CLASS_N» before anything reaches you. Numbering is stable across steps:
«PERSON_1» on step 2 is the same person as «PERSON_1» on step 9.

The redaction manifest lists every value that was removed, its class, and which
detector removed it. A field whose value is a placeholder is FILLED, not empty.
Do not re-enter it.

To put a known value into a field, emit its placeholder as the text. The device
will substitute the real value locally. «SECRET_*» cannot be used this way — if a
password or OTP is required, set done=false and explain what the user must do.

Refer to elements by the integer index in square brackets. Elements marked * are
new since the previous step. Elements shown without an index are visual-only and
can only be reached by coordinate.

Respond only with the provided JSON schema.
```

Follow this with one worked example showing the model reasoning correctly over a redacted
field — that example is what makes the scheme land. Add few-shot cases drawn from the actual
demo flow once M12 exists.

## Latency work — this is your metric

**Text-only fast path.** When the step carries no visual-only regions — which is most steps
on an ordinary form — send the element list alone to a text model and skip the image
entirely. This roughly halves step latency. Measure it; do not assume it.

**History trimming.** Keep the task, the last three steps and a running summary. Sending
twelve full element lists exhausts the context and slows every step after the fourth.

**Response validation.** Validate the model's output against the same schema server-side and
**refuse rather than return a malformed plan**. A refusal the client can retry beats a plan
that clicks the wrong thing on stage.

## Offline deployability

`server/docker-compose.yml` with pinned model weights, so the claim is demonstrable rather
than asserted. Write a short `server/OFFLINE.md`: how to pre-pull weights, what runs where,
and what the resource floor is. Test that the stack starts with the network disconnected
after the first pull — that test is a demo beat.

## Acceptance criteria

1. The stub server returns schema-valid canned actions within an hour of starting this
   session.
2. 100 consecutive guided generations parse without a retry.
3. Ten consecutive steps on the demo flow return schema-valid plans.
4. The model correctly **skips** a field whose value is a placeholder, and correctly **fills**
   an empty one using a placeholder from the manifest.
5. The text-only path measurably halves p50 latency versus the image path — number recorded
   in the trace.
6. Step 12 costs no more context than step 4.
7. `docker compose up` starts the full stack with the network disconnected after first pull.

## Do not

- Do not use a hosted API, even temporarily. If you need a stopgap, use the stub planner.
- Do not grow the action vocabulary beyond the nine operations in the contract. Every
  operation you add costs accuracy on the ones you already had.
- Do not store user data server-side. Sessions hold placeholders and indices only.
- Do not put retry logic for bad plans in the client. Refuse server-side.
